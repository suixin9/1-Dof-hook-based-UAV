![模型预览](designs/hook-v1/preview.png)

单位为 mm。单耳接口参考用户提供的厂家图；直杆直径10、长度400；半圆钩外宽67、钩子区域高110；整件总高551.5。接头与杆一体成型，无M10×1.25内螺纹。顶端圆角、打印补偿及生产公差未最终确认。

建议先打印接头试配件，再确定材料、打印方向、打印设备尺寸及是否分段。PDF 为设计核对图，不是最终承重生产图。
