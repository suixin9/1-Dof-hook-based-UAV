# F-SDA32CB 双耳支架：平板底座修改版 v1

本模型基于所提供的厂家尺寸图片，供外形核对、试配和试打印。不是厂家原始CAD，未标注细节不能保证完全一致。

修改：去除十字凸起和所有底座安装孔；底座改为平板；不包含中间销轴、卡簧或紧固件。保留两个同轴销孔。

| 参数 | 数值（mm） | 依据 |
|---|---:|---|
| 双耳外侧总宽 | 28 | 按图片标注解读 |
| 双耳内侧净距 | 15 | 按图片标注解读 |
| 单耳厚度 | 6.5 | (28-15)/2 |
| 单耳前后宽度 | 20 | 图片标注 |
| 销孔直径 | 10 | 依据图片销轴直径，孔配合公差未给出 |
| 孔中心距底座底面 | 22 | 图片标注 |
| 总高 | 32 | 图片标注 |
| 耳顶圆弧半径 | 10 | 根据耳宽和总高拟定为半圆 |
| 平板底座 | 44×44×4 | 一边44来自图片；另一边44及厚4为暂定 |
| 底板平面角圆角 | 2 | 暂定 |
| 耳根圆角 | 2 | 暂定，保留过渡但无十字凸台 |

15净距适用于耳部直段及孔附近；底部因耳根圆角局部变窄。

- `32cb_flat.step`：可用 Onshape / FreeCAD 打开、测量、修改。
- `32cb_flat.stl`：单位mm，打印模型；切片按100%比例。
- `preview.png` / `review_drawing.pdf`：尺寸及形状核对图。二维简图省略了圆角，以3D文件为准。
- `build.py`：CadQuery参数化源码。

验证：单个有效实体；STEP导出后重新导入验证通过。尚未确认实际配合公差、材料、载荷和打印工艺。请先试配，不能因几何验证通过就视为承重验证通过。
