# 电池底座与双耳支架一体件 v2（当前推荐版本）

按用户要求修改：
- 精确填实中央三个细槽，填充厚度与原电池板相同，为1 mm。
- 去除v1下方44×44×4 mm加强板，不再底座叠底座。
- 双耳直接从原电池底板下表面向下延伸，耳根保留2 mm过渡圆角。
- 其他原安装孔、四个边缘长槽、两侧大减重孔保留贯通。

方向与尺寸保持：112 mm长边前后，54 mm短边左右；销孔轴沿左右，hook前后摆动。双耳居中X=0、Y=-2.300636；内净距15，外宽28，各厚6.5，耳宽20，销孔直径10。销孔中心仍在原底板下表面以下22 mm；最低点以下32 mm；整件外形112×54×33 mm。

源电池板为1 mm厚；本版未增加整体厚度或额外加强板。支架端部形状与前版一致，仅耳根延伸至原板底面。实际强度、疲劳及销孔打印补偿未验证，请先试配。
