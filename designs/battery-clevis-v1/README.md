# 电池底座与双耳支架一体件 v1

用户确认：112 mm长边沿无人机前后；54 mm短边沿左右。支架放在底座下表面正中央。销轴沿左右方向，使hook在前后竖直平面摆动。保留44×44×4 mm支架加强底板，接受局部原开槽被遮挡。

坐标沿用输入STEP：X前后，Y左右，Z上。中心为X=0、Y=-2.300636 mm；原底板下表面Z=0，上表面Z=1。

新增支架由已提供32CB核对版旋转放置：加强板占Z=-4至0；耳部向下，孔中心Z=-22，最低Z=-32。合并件整体112×54×33 mm。双耳净距15，厚度各6.5，孔径10；加强板、耳根圆角等沿用32cb-flat-v1暂定尺寸。

原电池底座材料保留，无切除；加强板使中央及两侧部分原开槽成为盲槽，不再贯通。原文件备份为source_battery.step。双耳间不包含销轴；安装时需另外使用销轴和防脱结构。

文件：
- battery_with_clevis.step：一体精确实体模型。
- battery_with_clevis.stl：单位mm，100%比例切片打印。
- preview.png / review_drawing.pdf：核对预览。蓝色为原底座，橙色为新增支架；颜色仅用于说明，文件是一个实体。
- clearance_check.json：此前hook-v1模型绕Y轴每5度的静态几何重叠检查，单位mm3；零重叠不等于实际机构或载荷验证。
- build.py：建模及校验脚本；重建需本目录的source_battery.step及inputs目录中的支架和hook参考模型。

验证：合并后为单个有效实体；STEP导出重新导入通过；原底座材料完整保留。尚未进行强度、疲劳、打印质量、实物配合或无人机安装空间验证。

销孔10 mm未加入打印补偿，双耳净距15 mm配此前14 mm厚单耳，名义总侧隙1 mm。此前hook接头顶端暂定圆角等细节仍需试配。不能将几何检查当作承重验证。

与此前hook-v1模型在前后±90度范围内每5度采样，未发现实体重叠（37个姿态）。这是离散静态检查，未验证连续路径、实际销轴及机身其他部件。
